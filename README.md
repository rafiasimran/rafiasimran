# Hi, I'm Rafia 👋

I turn ideas into working AI products and connect the technical build with the business goal behind it. I study Engineering Physics & Data Science at Munich University of Applied Sciences, and I like taking something from a rough idea to a prototype people can actually use.

🏆 My team won **1st prize at the ZEISS AI Challenge 2026** with an energy app for microscope workflows: a rule-based model plus a Gemini-powered assistant that suggests fixes, demonstrated live on a held-out test scenario.

## What I work on

- **AI and LLM apps:** LLM apps, RAG, rule-based systems, fine-tuning, prompt workflows, automation with Zapier and n8n
- **Computer vision:** building and testing vision models with a volunteer AI team
- **Data:** Python (Pandas, NumPy, Scikit-learn, Matplotlib, Jupyter), SQL, Excel, Power BI
- **Cloud and DevOps:** AWS (S3, Lambda, Glue, Athena, IAM), Terraform, Docker Compose, Git, GitHub Actions
- **Databases:** PostgreSQL, SQLite
- **Quality assurance:** functional, regression and exploratory testing, test cases, bug reports, Jira

## Projects

**[Blog Automation Pipeline](https://github.com/rafiasimran/blog-automation-pipeline-showcase)**
A weekly GitHub Actions pipeline that drafts technical blog posts with the Gemini API, checks them against my quality rules and sends them to DEV for me to review. Python, REST APIs, pytest.

**[EcoScope: ZEISS AI Challenge, 1st prize](https://github.com/rafiasimran/ecoscope-zeiss-case-study)**
A dashboard MVP that finds idle energy waste in microscope workflow data, with an AI assistant that suggests fixes. I led the product side: problem definition, user stories, Figma prototype, pitch and live demo. [Live demo](https://ecoscope-five.vercel.app/)

**[TaxoSort: AI learning content classifier](https://github.com/rafiasimran/taxosort1)**
Sorts course titles into structured taxonomies (L&D, Bloom's, skills frameworks) with Claude, Gemini or OpenAI, and exports LMS-ready CSV. Single-file web app, no backend. [Live demo](https://rafiasimran.github.io/taxosort1/taxosort1.html)

**[Q-Volution Hackathon: Rigetti Challenge, Top 5](https://q-volution-hackathon.vercel.app/)**
Industrial energy optimization with quantum-classical hybrid methods on Rigetti quantum hardware.

**More I've built:** an AWS + Terraform ETL pipeline, and a SQL + Python data pipeline with data-quality checks and Excel reporting.
